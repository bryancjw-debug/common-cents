# Common Cents

Personal Finance, Simplified.

**Maintained app:** https://bryancjw-debug.github.io/common-cents/

This is the maintained React app, not the retired Personal Wealth Planner prototype. It includes individual/couple planning, CPF and CPF LIFE estimates, protection, property and other assets, taxes/SRS, investments, life events and detailed year snapshots.

Run `npm ci`, `npm test`, and `npm run build`. Start development with `npm run dev`. Production output is `dist`, including the scoped PWA shell. GitHub Actions tests and builds source before deploying **dist only**.

Existing CommonCents profile storage is retained. Prototype saved plans use a different format and are not silently imported or overwritten. Installation is not a backup. Projections are estimates, not personalised financial advice.
